# Identidad del Proyecto: Cognitive Suite
### Formerly Greys-v3

## ¿Qué es Cognitive Suite?

**Cognitive Suite** es un **runtime cognitivo local experimental**. Es una suite de herramientas diseñada para orquestar la relación entre un operador humano, un sistema local determinístico y modelos de lenguaje de gran escala (LLM) asíncronos.

Su nombre refleja un cambio de paradigma: de ser un "asistente personal" (Greys) a ser un **entorno de ejecución para la cognición aumentada**.

## Principios Fundamentales

### 1. Arquitectura Viva y Evolutiva
El sistema no es estático. Está diseñado para observar sus propios fallos, tensiones y cuellos de botella, sintetizando esta experiencia en nuevas capacidades locales (Reflejos).

### 2. Marcadores Epigenéticos (Reconciliación)
Cognitive Suite trata su memoria como un registro auditable e inmutable. Las interpretaciones sobre eventos pasados se añaden como capas de significado (etiquetas epigenéticas), permitiendo que el sistema aprenda sin destruir la evidencia histórica original.

### 3. Humano-en-el-Circuito (HITL)
La autonomía no es el objetivo; la **autonomía supervisada** sí. El sistema propone, el humano aprueba. Cada promoción de una habilidad experimental a un reflejo activo requiere una validación explícita basada en evidencia de quórum.

### 4. Local-First
La potencia del LLM es un recurso externo, costoso y latente. Cognitive Suite busca reducir la dependencia de estos modelos, convirtiendo el conocimiento externo en heurísticas locales rápidas, seguras y privadas.

### 5. El LLM como Maestro, no como Muleta
El modelo de lenguaje se utiliza para la planificación compleja, el análisis profundo y la síntesis de experiencia (Dream Mode), pero no para la ejecución de tareas triviales que el núcleo local ya ha aprendido a resolver.

## ADN Operativo
- **Evidencia antes de acción**: No se activan habilidades sin una masa crítica de casos de uso registrados.
- **Transparencia Total**: Cada decisión es rastreable a un ID de tarea, un plan cognitivo y un resultado de despacho.
- **Seguridad Inmunológica**: El motor IAFA evalúa continuamente el riesgo de las operaciones, protegiendo la integridad del sistema host.
